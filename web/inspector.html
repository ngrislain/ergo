Look inside the MCP connection.

Run the official MCP Inspector on your device, then display it here. Its backend stays on loopback: no public process launcher, proxy, or shared credentials.

  1. Save it as ergo-inspector.json in a writable folder. Inspector uses a separate construction cache.
  2. With a current supported Node.js and Ergo MCP installed, run:
    npx --yes @modelcontextprotocol/inspector@2.14.0 --web --config ./ergo-inspector.json
    Keep Inspector authentication enabled. Sign in to Ergo in the browser if prompted. Tool calls can publish real edits.
  3. Use the URL printed by Inspector. It is kept only in this tab, never sent to Ergo or saved.

Start the local Inspector before connecting. Browsers may request local-network permission or block embedded pages.
