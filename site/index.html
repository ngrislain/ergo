2

Add the plugin. Pick your agent.

The Ergo plugin connects the MCP tools and adds a build skill: find reference models, build at your location, inspect real views, and improve the result with you.

Use Claude Code, Codex or ChatGPT desktop, OpenCode, or Pi with local executable support. Other MCP clients can use the manual setup. The bridge runs locally over stdio; there is no public remote MCP endpoint.

1. Get the source plugins

Requires Git, Node.js 20+, and Chrome/Chromium on macOS or Linux. These are repository plugins, not public directory listings. OpenCode and Pi plugin packages are not yet published on npm. Review the source before loading a plugin. 

git clone https://github.com/ngrislain/ergo.git
cd ergo
2. Install the matching bridge & approve access

Run these in the cloned ergo folder. Local-path and desktop installs need ergo-mcp on PATH. The version comes from the plugin manifest, so it stays matched. No Rust build is needed. 

ERGO_PLUGIN_VERSION="$(node -p "require('./plugins/ergo/package.json').version")"
npm install --global --ignore-scripts "@ngrislain/ergo-mcp@$ERGO_PLUGIN_VERSION"
ergo-mcp --login --publish-url https://ergosandbox.com

Finish browser sign-in and approve the delegation, then choose your agent below. Sign-in is shared by bridge copies on this computer; never paste the token into a prompt or plugin file.

Claude Code

From the cloned folder, start a session with the plugin:

In your terminal 
claude --plugin-dir ./plugins/ergo

In Claude Code, use /ergo:build followed by your idea. For a persistent install, add this checkout with /plugin marketplace add ./, then run /plugin install ergo@ergo.

Codex & ChatGPT desktop

In a desktop host that supports local plugins, add the cloned repository as a local source in the Plugins Directory and install Ergo. Its marketplace manifest is .agents/plugins/marketplace.json; the plugin is plugins/ergo.

Ask the agent to use Ergo’s build skill with your idea. The desktop app must be able to launch ergo-mcp from PATH. A cloud-only chat or remote connector cannot run this local plugin.

OpenCode

Merge this into opencode.json in the cloned folder. In another project, use an absolute plugin path instead. Keep your existing settings and plugin entries.

Project configuration 
{
  "$schema": "https://opencode.ai/config.json",
  "plugins": ["./plugins/opencode-ergo"]
}

OpenCode loads the ergo MCP connection and the @ergo-build skill. Mention that skill with your idea; use /reload if you need to reload it.

Pi

From the cloned folder, install the local package:

In your terminal 
pi install ./plugins/ergo-pi

Start Pi, or use /reload in an existing session. Check pi mcp list or /mcp, then use /skill:build followed by your idea.

If the tools don’t appear

Check that ergo-mcp --help works in the agent’s environment. If connection times out during sign-in, finish ergo-mcp --login in a terminal, then reconnect the agent’s Ergo MCP server. Use a separate writable working folder for each concurrent agent; the default cache is construction.ergo.json.

Full plugin guide & installation details
1. Install the prebuilt npm package

Requires Node.js 20+ and a browser on macOS 13+ or Linux (glibc 2.36+). The native bridge and browser/WASM runtime are bundled. This package is available from %ERGO_MCP_PACKAGE_PROVIDER%. 

export ERGO_MCP_PACKAGE=%ERGO_MCP_PACKAGE_SHELL%
npm install --global "$ERGO_MCP_PACKAGE"
2. Start the MCP server 
ERGO_PUBLISH_URL=https://ergosandbox.com \
ERGO_PUBLISH_TOKEN_FILE="$HOME/Downloads/ergo-mcp-token" \
ergo-mcp \
  --workspace "$HOME/first-build.ergo.json"

Change the token path if you saved the download elsewhere. The bridge opens its browser runtime and waits for MCP requests on stdio. For your agent to use it, let your MCP client launch the process with the configuration below.

MCP client configuration

Paste this into your agent’s MCP settings and replace the absolute paths. Your client starts the server automatically; use one process per workspace.

Agent settings 
{
  "mcpServers": {
    "ergo": {
      "command": "ergo-mcp",
      "args": [
        "--workspace", "/absolute/path/first-build.ergo.json"
      ],
      "env": {
        "ERGO_PUBLISH_URL": "https://ergosandbox.com",
        "ERGO_PUBLISH_TOKEN_FILE": "/absolute/path/ergo-mcp-token"
      }
    }
  }
}

The workspace’s parent directory must exist. A missing construction file starts an empty build. See the full MCP guide for platform and runtime details.

Check your delegated edit allowance 
export ERGO_URL="https://ergosandbox.com"
export ERGO_TOKEN="$(cat /absolute/path/ergo-mcp-token)"

curl --fail "$ERGO_URL/api/shared-worlds/allowance" \
  -H "Authorization: Bearer $ERGO_TOKEN"

Use Authorization: Bearer for shared-world requests. Writes also require X-Ergo-Request: 1 and, for JSON bodies, Content-Type: application/json. Never put the token in a URL.

Start small. See what stands.

Open the sandbox, move to where you want to build, and ask your agent to use the build skill. Start with a small idea, review the rendered views, and ask for changes. Accepted production edits commit to the one public sandbox under your signed-in identity.

The renderer’s appearance is not a structural certificate. Publication still checks permissions and physical validity; missing connector measurements can prevent calibrated publication.

✳ A first prompt for your agent

Use Ergo’s build skill and MCP tools to build a small, grounded courtyard at my saved sandbox position. Search reference models with get_lego_models, check get_user_position and get_catalog, then build with suitable parts. Use get_build_feedback with include_images:true to show me real views and suggest improvements. Keep source attribution, explain any limitations, and return the confirmed shared_commit and view_url. Do not call an unaccepted preview a saved edit.

A few useful ground rules

Room to explore.
Clear boundaries.

A delegation that expires
Tokens default to 365 days, also the maximum. Generate a fresh delegation when it expires. Logging out doesn’t individually revoke an existing token.
10,000 changes, refilling daily
The free edit allowance refills continuously by 10,000 brick changes per day. It’s an edit budget, not a limit on the whole world.
Shared means shared
Hosted edits go to one public sandbox. Signed-in collaborators can build there under its permissions, edit allowance and authoritative validation checks.
